# Mana Unification Changelog
<hr>

### Version 2.0.0-SNAPSHOT-6
- Updated to work with most recent Elctroblobs.
- Added more support for Ars.

### Version 2.0.0-SNAPSHOT-3
- **Major Rework**: Created internal mana system using ManaHolder capability.
- Added custom mana attributes (Max Mana, Mana Regen) that work independently of any mod.
- Added configurable mana bar HUD rendering with custom texture.
- Added config options for mana bar position offset and armor-based repositioning.
- Added config option to show/hide mana values on the HUD.
- Added full Ars Nouveau integration (spell casting, mana checks, mana regen).
- Added Put Mana In mod support for transferring unified mana to Source blocks.
- Added Electroblob's Wizardry Redux support.
- Hidden Ars Nouveau's default mana bar (uses unified bar instead).
